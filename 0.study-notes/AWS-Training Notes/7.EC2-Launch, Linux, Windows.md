[[0. AWS-SAA-Training Overview]] [[6.EC2-Architecture&Cost]]


Key Pair- Public/Private key pair. 
	RSA and ED25519 types, file types .pem and .ppk
	AWS gives you the private key to download. And you instance gets the public key. 
	This key pair is used for authentication. 

Network settings- allows you to provision the network for the instance
	Select you VPC, Subnet, select auto assign public IP IF your architecture requires it. 
	In the firewall setting you can apply created existing security groups: i.e. allow ssh, allow https/https, allow outbound rules etc. 
Create IAM for the EC2 to access the S3. 

User Metadata in the instance- data about your instance that you can use to configure or manage the running instance. i.e. Asses, in console CLI run: curl http://ip-address/latest/meta-data. Enable "Metadata accessible" when provisioning a server. 

Instance User Data- you can add commands used at instance launch to automate installation actions. I.e. you can do all server updates and etc. Linux or Powershell commands.
