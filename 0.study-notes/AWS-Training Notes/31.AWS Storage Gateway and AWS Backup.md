 [[0. AWS-SAA-Training Overview]]  

**AWS Storage Gateway**- Hybrid storage service that uses S3. Enables your on-premises applications and servers to seamlessly use AWS cloud storage
	Uses: Backup, archiving, disaster recovery, cloud data processing, storage tiering, migration of non-prem
Features: 
	Highly optimized data transfer
	Bandwidth management
	Automated network resilience
	Efficient data transfer
	Local caching for active data to reduce latency. 
**Storage gateway Options**
File gateway- *NFS* (v3 and v4) or *SMB* interface (Linux or Wind. servers, you want to take on prem.)
	On Premises *file storage* backed by S3 objects
	Store application data files and backup images as durable objects in S3.
	Local caching option
Volume Gateway- iSCSI block interface (if you have iSCS servers)
	On prem. *block storage* backed by S3 with EBS snapshots
	Options: Gateway Stored Volume (using S3 for backups) and Gateway Cached Volume (Both access data AND backup data)
Tape Gateway- iSCSI virtual tape library interface (for archiving iSCS)
	Virtual *tape storage* in S3 and glacier with VTL management
	Use cloud for backup/archiving jobs (S3, Glacier). 
	Integrates with existing tape infrastructure

**AWS Backup**- Integrated into many services. Fully managed
Centralized Backup service: schedule, Automate
Services: FSx, EFS, DynamoDb, EC2, Aurora, RDS, EBS, AWS storage gateway
Backup stored in S3.
