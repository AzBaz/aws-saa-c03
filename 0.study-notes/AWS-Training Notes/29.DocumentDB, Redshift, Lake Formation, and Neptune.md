**DocumentDB**- Stores documents( ie. JSON format docs, MongoDB)
Fully managed; Fast; Flexible; Reliable; MongoDb-compatible

**Amazon Redshift**- Fully managed, highly scalable, *clustered* petabyte-scale data warehousing(hard drives), exabyte-scale data lake solution (Exabyte scale, S3)
Designed for very large datasets
Supports structured and unstructured data
Uses SQL
Uses a variety of optimizations for analytic and reporting workloads
Cost effective
Suited for OLAP and Business Intelligence workloads
Durable. 

**AWS Lake Formation**- Build, manage, and *secure data lake* in days (Exabyte scale; Stored in S3)
Centralized service where you can:
	Discover data sources
	Set up transformation jobs to move data to an S3 data lake
	Remove duplicates and match records
	Catalog data for access by analytic tools
	Configure data access and security policies
	Audit and control access from AWS analytic and ML services. 

**Neptune**- A *graph database* service
Fast, Reliable, Fully managed
Build and run apps that work with highly connected datasets (i.e. Recommendation Engines, Fraud Detection, Knowledge Graphs)
Optimized for storing billions of relationships and querying the graph with milliseconds latency.
