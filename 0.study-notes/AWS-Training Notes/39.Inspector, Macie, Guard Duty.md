**Amazon Inspector** Automated security assessment service. EC2
Helps you to test  the security state of your EC2 instances and the Apps running on them. 
- Security best practices
- Uses CVE database to detect and find security vulnerabilities. 
- CIS operating System Security Configuration Benchmarks
- Runtime behavior analysis
Report provided in PDF format. 
Easy to deploy, manage and automate. 

**Amazon Macie** Data security and Privacy service for S3
Protects sensitive data in AWS
- Personally Identifiable Information
- financial data
Discovers any sensitive data
Provides an inventory of S3 buckets
Evaluates and monitors of S3 buckets
Evaluates and monitors buckets for access controls

Findings are provided for review and remediation, as soon as they are detected. 

**Amazon GuardDuty** - Continuous security monitoring service
Analyzes and Processes
- VPC flow logs
- CloudTrail Management event logs
- CloudTrail S3 data event logs
- DNS logs
Using threat intelligence feeds

Findings provided in GuardDuty or CloudWatch, whenever it detects unexpected and potentially malicious activity.
