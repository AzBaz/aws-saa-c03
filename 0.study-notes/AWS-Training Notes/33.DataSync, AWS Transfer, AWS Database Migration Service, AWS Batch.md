**AWS DataSync** - Online data transfer service, from on prem to AWS or AWS to AWS
Supports: S3, EFS, FSx
Only pay for what you copy
Use Cases: Data Migration, Data Protection, Archiving of cold data, Data Processing for Hybrid workloads.

 *As of 6/23/2026* 
Transferring hot or cold data should not impede your business. DataSync is equipped with granular controls to optimize bandwidth consumptions. Throttle transfer speeds up to 10 Gbps during off hours and set limits when network availability is needed elsewhere.

**AWS Tansfer** - Fully managed, File Transfer server. 
Into and Out of S3 and EFS. 
Supported protocols: FTP, SFTP, FTPS

**AWS Database Migration Service** - Migrate relational, NO SQL Databases, Data Warehousses, other types of data stores
Features: Fllet Advisor- Discover source data and Source Infrastructure. 
	DMS Schema Conversion- Migrate to a different database engine
	DMS- Migrate your data. 
You can perform: One-Time migrations, Replicate Ongoing changes to keep sources and targets in sync. 


**AWS Batch**- Helps to run batch computing workloads on AWS cloud. Fully managed service.
Automatically provisions compute resources
Automatically optimizes the workload distribution.
