Internet gateway (IGW)- required for internet; allows VPC to connect to the internet
	Reliable, available, and scalable by design. No need to manage it. 
	 Only HAVE to build the Internet Gateways
	 Both IPv4 and IPv6 traffic
**An internet gateway CAN only be attached to 1 VPC. **

-Once it is attached, it CANNOT be attached to other VPC
-For the internet gateway to start working you need to link it to your existing route table. 
-Route table is automatically created with a VPC. 
-Then you can re-name the route table and see the routes leading to every single IPv4 and IPv6 addresses.
-Traffic can be routed based on the route table

**Subnets:**
-Every single one of your subnets is connected to your default route table.
-Modify the route table to build a default route; and any resources on the Subnet to talk to the internet need IGW

-Your Internet GateWay (IGW) is at 0.0.0.0/0 
For IPv6 ::/0 

-By default once you setup your subnet and IGW and link them together via routing table, your subnets get a public internet access. 

-To make several subnets such as (app or DB) you need to make those subnets private. 
-Only the website needs to talk to the internet, so make it public.
-Never let app or database to be public. Always make app and database private subnets.
-Have a different route tables for every single of your subnets. And you can controll them individually. 

-Public Subnet- Has internet connectivity through public subnet. 
-Private Subnet- Has internet connectivity through private subnet.
	Does NOT cave connectivity to Internet GateWay.

**NAT

If app/database server needs to connect to the internet for updates or for other tasks, you can set up a VPN connection to download updates. 
Or you cant take those devices to the public internet, do updates, and come back to private subnet. 

-USE Network Address Translation (NAT)
-When you need your resources on the private network/subnet to talk to the internet you build NAT for it. 

**DO NOT pick NAT Instance as your answer choice for the network address translation. This is covered in case EC2 NAT instances are asked on the exam. 

Build an EC2 server that can do network address translation. 
-Build NAT instance on public subnet (because it has internet connectivity)
-Then point those route tables to NAT instance.

EC2 instance/server, has a default feature Source/Destination checking, EC2 accepts packet only sourced to itself. A security feature. Need to turn off this feature for the NAT to work. SRC/DST checking OFF.

EC2 NAT instance is NOT scalable so it can fail sometimes. 
Add second NAT instance for more reliability.
Building server each time for NAT, can become costly and reduntant. 


**NAT Gateway

You can easily deploy the NAT gateway in your **public** subnet. This let's your devices in private subnet, can go to internat via NAT Gateway.

You CAN create as many VPC, Subnet, Route tables as you want, and it is FREE.
BUT NAT Gateway starts costing money. 

Create NAT Gateway:
	Only in public subnet
	 Assign one elastic public ip address (static ip)-helps to talk to internet
	 AWS gives you one private ip address-talk to everything else. 

Modify the route tables of your private subnets to point them to NAT Gateway
	Add a route 0.0.00/0 via NAT Gateway
		Do this for every private subnet if you want the internet connectivity. 
		This is for IPv4.
	With private IPv6 subnets, eventhough if you have public IGW via NAT, you still cannot get to internet.  
		For IPv6, you **EGRESS-ONLY** IGW
		Build Egress-Only IGW for IPv6

Create Egress-Only IGW:
	Give a name
	 Select VPC
	 Route tables
	 ::/0 point to Egress Only Internet Gateway (EOIG)


**Network Firewall

Managed network firewall service for Amazon VPC.

-You can use Cisco, Palo Alto, Fortinet firewalls. But they are going to be EC2 instances running that firewall. So you will have to scale the EC2 for throughput, scale up/scale down. 

So AWS can do all of that for you without you having to provisioning a new EC2 for firewall

Firewall has its own subnet. 

Create firewall
Configure firewall policy
Edit your route tables to go through firewall
