**Identity Providers** - Managed identities outside of AWS
Grant Outside identities permissions to use AWS resources in your account. 

For Identity providers you can use:
Your own corporate user directory
	SAML 2.0-based identity providers
	Use existing corporate identities instead of creating new identities in AWS when access/managing resources
Third-Party (Web) Identity Providers
	OpenID Connect (OIDC)
	When creating a mobile app or web application that requires access to AWS resources.

**Amazon Cognito** - Provides authentication, authorization, and user management, for your web and mobile apps
	User can sign-up and sign-in directly with a username and password through a third party (acts as identity broker), i.e. Facebook, Amazon, or Google
	Also supports anonymous guest users
	Supports MFA
*Amazon Cognito Sync (AppSync)*- synchronize user profile data across mobile devices and the web, various platforms. 
	Uses "Push Sync" feature.
