 [[0. AWS-SAA-Training Overview]]

*Storage TYPES:*

**Instance Store**
Block storage- on host
Latency- lowest; consistent
Single instance access- Mounted to an instance
Not persistent- temporary
Not highly available
Not highly durable

**Elastic Block Store (EBS)**-Hard drives on storage area network. Within same AZ as the instance
Block storage
	Separate from host
	Same AZ as host
Latency- lowest; consistent
Single instance access- Mounted to instance
Persistent- if configured
Highly available
Highly durable
*Types of EBS*- SSD, HDD, throughput optimized HDD

**EFS(elastic file system)** and **FSx**
Share date the ones on the storage volume.
File system- separate from host; Regional
Latency- low; consistent
Multiple instance access- Mounted to instances
Persistent
	Highly available/durable
In exam:
	EFS-Linux ONLY!
	FSx-typically SMB/Windows

**S3-Simple Storage Service**
Usually connected to via API call
Stores objects- separate from host; Regional
Latency- low; NOT consistent
Multiple instance access- Web based / API
Persistent
Highly available/ Highly durable
