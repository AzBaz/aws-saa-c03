[[0. AWS-SAA-Training Overview]] [[6.EC2-Architecture&Cost]]


**EC2-Elastic Compute Cloud**: Virtaul servers known as servers. Scalable up and down, out and in. Pay per use. 

EC2 goes with Instances or Instances. 
Pricing options of EC2 instances will be tested. 

**Scale Up/Down**= Power UP (more storage, RAM, entworking) Power DOWN
	Scale Up/Down is more challenging than scaling Out/In
	 Capacity and Usage may not match in scale Up/Down. While Scale Out/In has capacity and usage almost equal. 
	 Consider scale out/in, before up/down. 
	 
**Scale OUT**= More servers (not more resources)= Highly Available, Reliable, Cost Efficient (more servers can be cheap than scale UP).
	Can be more reliable, available and faster. 
**Scale IN**= Less servers.

Storage available on the EC2 itself OR via EBS Opimized Network, S3 (static objects), EFS, FSX

**Pricing:** Free tier, On-Demand, Svaing Plans, Reserved, Spot, Dedicated Hosts, Dedicated Instances, Capacity Reservation. 
	On-Demand- Pay per usage. Launche the instance when you need it. Only pay the hourly instance of the instance you use. 
		Low cost, flexible options. No upfront payments or long term commitements. 
		 For apps- short term, spiky, unpredictable workload that can't be iterrupted
	Savings Plan- For website to be up 24/7, but youneed to make a commitment to AWS 1 or 3 years.
		Compute Svaings-Pay AWS upfornt, instead of on-demand. includes EC2, Fargate, lambda
		EC2 Savings- Only EC2 instances
	Reserved Pricing- AWS recommends Savings-Plan now instead of Reserved Pricing. 
		Significant savings but 1 or 3 years term of commitment; flat cost. 
		Standard Reserved: Allows to change AZ, Instance size, networking type.
		Purchase Convertible Reserved Instances- gives additional flexibility, different OS, instance family (macro, micro, nano)
	Spot Instances- requesting a spare compute capacity, cheaper than On-Demand, but cost is dynamic, it can change up. Set by AWS EC2, adjust gradually based on long term trends in supply and demand. Price can increase while you using it. AWS Can terminate your service on Spot if you do not want to pay On-Demand standard pricing. 
		For apps that have flexible start and end time. 
		For apps only feasible only at ver low compute prices
		Users with urgent computing needs for large amounts of additional capacity. 
	Dedicated Hosts- dedicated hardware to support existing software licenses and improve complince. On EC2 console
		Bring you own software licesnses = Dedicated hosts -> ANY Exam Question. 
	Dedicated instances- Build a VPC that use dedicated tendency, because you use dedicated tendency so you build a server, and you need it on dedicated hardware. Seperate, not on shared architecture. Usually more expensive than shared hardware. 
	Capacity Reservations- Ability to reserve servers that have specific capacities WHEN you NEED them. 
		Ensures you have services when you need them. Scheduled Reserved instances, can spin up a service on certain date and time.
