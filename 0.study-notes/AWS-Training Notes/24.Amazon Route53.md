**Route53** - DNS webservice
It does: name registration, name resolutions, end user routing based on latency, location, weight. 
Based on the name servie you do, you can keep health of the resource that uses the domain name. 

**Route53 Routing Policies**
Simple- Create 1 record that conatins one or more IP addresses
	All IP addresses returned to the client in a random order. 
	Client use addresses in the list. 
Multivalue Answer- Provide multiple IP addresses to the client. (Must be all active resources)
	Control returned IPs based on the health of the resource. Allows health checks.
Weighted- You specify multiple IPs and the percentage of traffic. Multiple resources that do the same job, but you control the traffic where it goes to.
	Reoute53 responds to clients based on the percentage you gave
Latency-  You create records for the regions you host resources in. 
	Route53 determined which region gives the user the lowest latency
	Route53 responds with the value from the selected record. 
Failover- Used for active/passive configuration (resources active/passive)
	You specify primary and secondary record
	Route53 monitors health of primary; if it's unhealthy, secondary record is used. 
Geolocation-You specify who accesses what resources based on geography
	Origin of DNS query determines your geographic location
Geoproximity- You specify who accesses what resources based on geography. (Expand/Shrink) uses bias to control the size of the geographic region
	Origin of DNS query determines your geographic location. 

**Routed53 Supported Records**
A (Apex domain i.e. x.com) and AAAA- www.x.xom - 192.2.2.2.or 2002:db8:A:B::1
CAA- Identifies the Certificate Authorities that can issue ssl/tls cert. 
CNAME- ftp.x.com = www.x.com
MX- Identifies mail server
NS- Used to identify name servers authoritative to your zone
PTR- Used for reverse DNS lookups

ALIAS Record- Used to provide CNAME like behavior when you need other record for the APEX domain anem

AWS Uses: Route queries to CloudFront, Elastic Beanstalk, S3 bucket, Other Route53 resource record sets.
