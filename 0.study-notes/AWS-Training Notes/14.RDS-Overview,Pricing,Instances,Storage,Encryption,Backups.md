[[0. AWS-SAA-Training Overview]]

**RDS**- Managed database web service
	Simplifies the setup, operation, management, maintenance and scaling of structured relational databases (SQL).
	Scale resources independently (up/down)
		CPU, IOPS, Storage, memory, Networking
	OS and DB engine patching handled by AWS
		Automatically or manually (you can choose when to have patches)
	Backups
		Automated backups of entire instance once a day
		Manual backups performed anytime you need. 
	Reliable efficient restoration
		Entire instance with your DB point in time restores
	High availability
		Multi-AZ deployment for disaster recovery only
	Read Replicas- for improved performance and recovery. 
Supports: Amazon Aurora, MariaDB, SQL Server Microsoft, MySQL, Oracle, PostgreSQL

**RDS Pricing**
On-Demand- Pay by the hour for the DB instance hours that you use.
Reserved instances- Reserve a DB instance for a one year or three year term and get a significant discount compared to the on-demand DB instance pricing. 

**RDS Instance Classes**
	General purpose- Balanced memory, CPU, networking
	Memory Optimized- For memory intensive workloads
	Burstable Performance- Baseline performance than can burst higher if you have the credits. 

**RDS Storage**
	General Purpose SSD- Cost effective storage that is ideal for broad range of workloads running on medium-sized DB instances. 
		Best suited for development and testing environments
	Provisioned IOPS- Meet the needs of I/O-intensive workloads, particularly database workloads, that require low I/O latency and consistent I/O throughput.
		Best suited for production environments.
	Magnetic- For backward compatibility if need but not recommended to use. 

**RDS Encryption**
	Encryption at rest
		Includes the underlying storage for DB instances, logs, automated backups, read replicas, and snapshots
	RDS uses KMS keys for Encryption.
	Enable encryption when you create the instance for the first time. 
	Enable encryption from an unencrypted snapshots that you copy and encrypt then build a new DB with it. 
		Will have a new endpoint access for the new encrypted version of the image. 

**RDS Backups**
Creates a storage volume snapshot of your entire instance and database
First snapshot is full and the rest are incremental
	Recover  your database to any point in time.
Backups stored in S3
Automatic Backups
	During the backup window of your database
		Retention Period of 1-35days
Manual Backups
	For longer retention days. 

*AWS Backup*- Fully managed service that makes it easy to centralize and automate backups
	Supports RDS database engines and Aurora clusters
Create a backup vault for RDS
Create a backup plan- Set an expiration/retention period for the backups.
Assign the RDS Instance to the plan.
