**AWS Certificate Manager (ACM)**- Create, store, renew public and private SSL/TLS X.509 Certificates
Centralized and Fully managed
	Issue new certificates in ACM
	Import existing third-party certificates into ACM
Use the certificates in other services that ACM is integrated with, like CloudFront, Elastic Load Balancer, and API Gateway. 

**AWS Secrets Manager**- Protect "secrets" that are used to access apps, services, and resources.
Rotate/Manage/Retrieve secrets such as:
	Database Credentials
	API Keys
	Passwords
	OAuth Tokens
Eliminates the need to embed the credentials in applications and services. 

For automatic key rotations, you need to enable Automatic rotation, schedule the rotation time, and code the Lambda Function. 

**AWS WAF (Web App. Firewall)**- Protects web apps from various attacks. 
Allow, Block, Monitor web requests by: IP Address, HTTP header, HTTP body, URL string, SQL injections, Cross-Site scripting, HTTP Flood, Geography

Designed for: *CloudFront, APP Load Balancer(http/https req.), API Gateway, and AWS AppSync*
	Therefore bad requests are stopped before reaching servers and services. 

**AWS Shield** - Protects web apps from DDoS attacks
Standard - Free
	Layer 3/4 protections: SYN/UDP floods, Reflection Attacks, and other 3/4 attacks
Advanced- Cost thousand/month
	Enhanced protection for larger more sophisticated attacks on: EC2, ELB, CloudFront, Global Accelerator, Route53
Flow-based monitoring of networks traffic
Active application monitoring
DDoS cost protection feature.
