**Replication**- Used to Replicate objects in a bucket to another bucket
	Bucket names are unique so once you replicate the object its not technically the same object and it will have a *different path*.
		Thus, any application or service you have would have to account for this. 
![[Pasted image 20260616153112.png]]


**Server Access Logging**- Provide detailed records about requests that are made to a bucket
Great for: Security; Access Audits
Access Log record contains a lot of information i.e.:
	The request type
	The resources that are specified in the request
	Thee time and date that the request was processed and etc. 

You need to create another bucket that will collect the logs that are generated. 
	Not recommended to records the log into same bucket you turned on logging for. 

**Requester Pays**- By Default, bucket owners pay for all S3 storage and data transfer costs associated with the bucket.
Requester Pays bucket, the requester instead of the bucket owner pays the cost of the request and the data download from the bucket
	The bucket owner always pays the cost of storing data. 

**S3 Inventory**- Used to help you manage your storage
Provides an output file in one of the following formats: CSV, Apache optimized row columnar ORC, Apache Parquet.
Files list your objects and their corresponding metadata on a daily or weekly basis for an S3 bucket or a shared prefix
![[Pasted image 20260616163913.png]]

**Storage Lens**-Cloud storage analytics feature. 
Organization-wide visibility into object-storage usage and activity
Examples:
	Find how much storage you have across entire org
	Find the fastest growing buckets and prefixes
	Find which buckets are rarely accessed
	Identity cost-optimization opportunities
	Implement data-protection and security best practices
	Improve performance of application workloads
	Identify buckets that don't have s3 lifecycle rules
	Identify incomplete multipart uploads that are more than 7 days old.

**S3 Event Notifications**- Send a notification when specific events occur in your bucket
	Object creation/Removal/Restore
	Object ACL
	Object Tagging
	Reduced redundancy storage
	Replication
	Lifecycle
	Intelligent Tiering
Destinations- Lambda, SNS, SQS.
