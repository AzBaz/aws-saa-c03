AWS gives a default VPC for each region
	For quick deployment you do not need to build a VPC

Anything that requires multi tier applications, we NEED to build a VPC

VPC is a regional based service.
Diff. regions have diff. VPCs. 

There are 6 subnets by default that associated with a default VPC. 
	1 subnet per AZ
Default route table and gateways. 


VPC is based on an entire REGION. 
Associated with CIDR block (IPs)

Prod-VPC; Dev-VPC; Testing-VPC -> all isolated from each other and different IPs. 
	By default they cannot talk to each other. You will need to set up VPC peering.


Example: 2 AZ's, A & B = 1 VPC.

Make sure subnets do not overlap. 
For IPv4 use somthing like this: 10.0.0.0/16 (10 network)

For IPv6 use free one given by AWS or your own. 

Tenancy: are you sharing the physical servers by other customer? (is Default on AWS)
	Use dedicated to have your own physical resources. 

Tags- add tag values for depts. or dev. environments (testing, dev, prod).
	Helps to track your bills and cost.
	 Create your own tagging strategy. 

Use AWS docs. to learn more: https://aws.amazon.com/documentation-overview/


Subnet- a logical section in a VPC, where you place your resources in. 
i.e. = web subnet, app subnet, db subnet. 
Subnets are scoped to an AZ. 

Public vs. Private Subnets

Private Subnets: resources accessible within AWS on or via VPN/Direct Connect. 
	Private addressing. 

Public Subnet: Any subnet in your VPC, where resources are available from Internet and within AWS. 
	Private Adressing (RFC 1918).
	
IP adress does not determine wheter subnet is private of public. ONLY controlled via access. 

IPv4: Randomly chosen chosen by AWS. 
	When EC2 is terminated, you have to give back the public IP address
	 If EC2 stops and starts, public IP changes
	 if EC2 is rebooted, public IP DOES NOT change.

Elastic IP:dedicated IP upon request. 
	Free if assigned to a server. 
	 NOT free is elastic IP is not assigned to server

Private IP: specific range; auto assigned when creating an instance
	RFC 1918
	 Custom range determined when creating a VPC and Subnet
	 Auto assigned to a server; remains with server until terminated.

First address is not usable and last address is also not usable
i.e. 10.0.1.0 = NOT USABLE=Network Address

i.e. 10.0.1.1 = NOT USABLE= VPC Routes address
10.0.1.2 = NOT USABLE= DNS Server address
10.0.1.3 = NOT USABLE= Set asisde for future use.
