**AWS Organization** - Simplifies the management of multiple accounts at once. 
Organize multiple accounts in a hierarchy and manage centrally. 
- Primary account at the top and member accounts under
- Primary account pays for all (consolidated billing)
- Primary account defines SCPs (Service Control Policies)- Apply policies to member accounts. 
	- Define maximum permissions (guardrails) for accounts/OUs. They do not grant permissions, only limit them.
	- SCPs affect IAM users and roles but never the management account.
	- Effective permission = intersection of SCP + IAM policy. Both must allow.

**AWS Control Tower** - Set up and govern a secure multi-account AWS environment. Built on top of AWS Organizations. 
- Landing Zone- A well architected, multi-account baseline that follows AWS best practices
- Guardrails (AKA Controls)- Implement governance rules  for security, compliance and operations
	- Preventive controls are implemented with SCPs
	- Detective controls are implemented with AWS AWS CloudFormation hooks

*Organizations vs Control Tower (exam distinction)*
- *Organizations,* the raw building block; you configure everything manually.
- *Control Tower*, opinionated automation layer that sets up Organizations correctly for you with guardrails and dashboards. Choose it when you want a governed multi-account env fast.

**AWS Resource Groups**- Used to organize your AWS resources. Logical grouping of AWS resources so you can *view, manage, and automate* them together. Not related to account management (do not confuse with Organizations).
- Default- resources are groups by service
- Resource Groups- you define how they are grouped
	- Tag Based
	- AWS CloudFormation stack-based. 
- Works with *Tag Editor* to find and bulk-apply tags across resources/regions.
- Enables running automation/operations against a whole group (e.g., via *Systems Manager,* patching, or bulk actions).

*Use cases*
- Organize resources per project, environment, or application.
- Apply operations (patching, monitoring, automation) to a set of resources at once.

*Exam traps*
- Resource Groups = operational grouping within an account (tag-driven).
- Organizations = account-level management across accounts. Questions may test that you know the difference.
