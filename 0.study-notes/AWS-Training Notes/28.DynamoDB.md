**Amazon DynamoDB** - Fully manages NoSQL (schemaless) database.
Multi AZ for high availability
Fast and Predictable performance; Use DAX(Dynamo DB Accelerator- builds cache in fron of DynamoDB) for even better performance. 
Unlimited automated scalability
Distributed (scale out/in)
Great for: User profiles, Shopping carts, High Volume read/write applications, Games, IoT devices
*Dynamo DB*- NO hardware provisioning; NO setup and configuration of OS or DB Engine; NO need to replicate; NO need to patch; NO need to manage cluster scaling. 
![[Pasted image 20260619101948.png]]

**DynamoDB Storage**- Data is stored across multiple SSD drives in multiple storage locations in a single Region; Ensures durability
Due to multiple storage locations:
	Data is *eventually consistent* across all storage locations, usually within one second or less after it is replicated. Thus, *reads may not return the most up to date results all the time* as you can read from any location. 


**DynamoDB Modes**
On Demand: When you have sproadic/unpredictable access patterns
Provisioned: When you know what the access patterns will be like
	Set the RCU (Read Capacity Unit) and WCU(Write Capacity Units)
	Use Auto-Scaling for temporary spikes in access patterns. 

**DynamoDB Accelerator (DAX)**- In-Memory Acceleration/Cache
Results are stored in a memory cache
Sub-millisecond latency
Great for when you have the same information being heavily read over and over. 

**DynamoDB On-Demand Backups**- Built IN
Not centralized
Performed on the table
Backups are only available for the same acount
Backups are only available for the same Region

**AWS Backup**
Centralized
Backups can be copied to other Regions
Backups can be copied to other accounts
Add tags to backups
Transition Backup to lower cost storage for long term retention. 

**DynamoDB Point in Time Recovery** - Continuous Backups that you can use to restore your table to any point in time during the last 35 days. 
DynamoDB maintains incremental backups of your table
Protect your DynamoDB tables from accidental write or delete operations
No need to worry about creating, maintaining, or scheduling on-demand backups. 

**Deleting Items from a table**
Manually: In console; Using CLI, Coded in an APP
DynamoDB TTL: Delete an item from a table once the TTL expires
"Start Over": Delete the entire table recreate it.
