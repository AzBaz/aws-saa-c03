**Step Functions**- A web service that enables you to coordinate the components of distributed applications and microservices using visual workflows.
Ensures your application executes in order and as expected every time. 
Allows you to coordinate individual tasks by expressing your workflow as a finite state machine, written in the Amazon State Language.
