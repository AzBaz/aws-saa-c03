You can host a static website by serving it via S3 bucket. 
Basic static website with html, css, javascript files.

You have to **turn on static website hosting** via the bucket
	Under  Properties tab -> turn ON Static website hosting 
**Static website hosting via S3 bucket will always be http and NOT https.** 
	To enable https you need to put CloudFront to offload https request there. 
	Use CloudFront with the static website as the source
	Set it up so https from client to CloudFront and then CloudFront to static website will be http

**Website Domain**-You can fix the endpoint name (website name) via Route53, by creating a new name record, pointing to an existing domain name that will serve the S3 bucket static website. 

PHP, Python, Java, Ruby or Asp.Net- that i**s dynamic content NOT static** CANNOT use S3 web hosting.
	Needs server or Lambda Function
