**S3 Storage Classes**
For Frequently accessed Objects
	Standard
	Reduced Redundancy
For Infrequently Accessed (IA) Objects
	Standard-IA
	One Zone-IA
For Changing or Unknown Access Patterns
	Intelligent-tiering
For Archiving Data
	Glacier
	Glacier Deep Archive-data accessed once or twice a year and can be restored in 12hours.
	Glacier Instant Retrieval- ling lived files archive data accessed once a quarter with instant retrieval in milliseconds

**Lifecycle Policies**
Attach lifecycle policy directly on the bucket. 
Define storage actions S# should take on object
	Transition object to another storage class
	Archive object to Glacier
	Delete object after a period of time
Define policy on entire bucket or subset of object in bucket
	Transitions: S3 to S3-IA to Glacier
	Expirations: Permanently delete after X days.
