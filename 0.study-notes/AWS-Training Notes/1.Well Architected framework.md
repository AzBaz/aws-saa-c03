[[0. AWS-SAA-Training Overview]] 


Availability Regions and Zones. 

Regions contain AZs. 

Some Regions and AZs are not available due to some restrictions. 

Some services do not have an AZ.

However, for another set of solutions you have to pick Region and AZ. 

Usually not tested on how many AZs or regions are therese, because they keep changing a lot. 


AWS Route 53= a DNS solution ( can manage which regions to go to)
	Can control which region to go to.

Route 53 automatically recognizes region availability and ca re-route accordingly.

Odds of region failing is slim, But if you can't tolare failures, you have to know how to manage different regions.

1 Region has 3 (or more) AZ's

If resources deployed in 1 AZ, and the AZ fails, services fail as well. 
	Now do a replication in the same Region with different AZ, so services keep running. 
	Will cost more money, but still cheaper than migrating Region to Region. 

Edge location (AWS Edge Network Location)= DataCenter location in a major city that is physically connected to AWS gloabl infra. 
	Low latency, close to the user. 
	Improve security.
	 Can stare chached file at edge location, and user can ping that edge location instead of the AZ. (sppeds up the access to the content)
		 i.e. Netflix streaming.
