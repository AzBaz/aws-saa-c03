## Amazon Athena
**Serverless, interactive query service**. Run **standard SQL** directly on data in **S3**. No servers, no loading.
Analyze petabytes of data where it lives.
- **Pay per query** (per TB scanned). No infrastructure to manage.
- Uses **Presto/Trino** engine under the hood.
- Reads data in place from S3: CSV, JSON, Parquet, ORC, Avro.
- **Cost optimization**: use **columnar formats (Parquet/ORC)**, **compression**, and **partitioning** to scan less data = cheaper + faster.
- Uses **AWS Glue Data Catalog** as its table/schema metastore.
- **Federated queries** can hit sources beyond S3 (RDS, DynamoDB, etc.) via connectors.

**Scenario cue**: "query data in S3 with SQL, no infrastructure" → Athena.

## Amazon QuickSight
Business intelligence- Deliver easy to understand insights to anyone anywhere. 
	**Serverless BI / dashboard and visualization** service. Turns data into interactive dashboards.
Data from: AWS Data, Third party data, Big Data, Spreadsheet data, SaaS data, B2B data. 
	Connects to many sources: S3, Athena, RDS, Redshift, RDS, on-prem DBs, SaaS.
- **SPICE**, in-memory engine for fast queries without hitting the source repeatedly.
- **ML Insights** (anomaly detection, forecasting) and **natural language queries** (Q).
- **Per-session pricing** option; row-level security for restricting data per user.
- Embeddable dashboards into apps.

**Scenario cue**: "build dashboards / visualize data for business users" → QuickSight.

## AWS Glue
**Serverless ETL** (Extract, Transform, Load) and data integration service. Prepares and moves data for analytics.
Use for: Analytics, Machine Learning, App Development
Can connect over 70 data sources
- **Glue Data Catalog**, central **metadata repository** (databases, tables, schemas). Used by Athena, Redshift Spectrum, EMR. One catalog, many consumers.
- **Crawlers**, automatically scan data sources, infer schema, and populate the Data Catalog.
- **ETL Jobs**(extract, transform, load), run transformation code (Spark/Python) on a serverless, auto-scaling backend.
- **Glue Studio**, visual ETL job builder.

- Fully serverless; you do not manage clusters.
- Ideal for schema discovery and prepping S3 data before Athena/Redshift query it.
- **Job Bookmarks**- Tracks data that has already been processed during a previous run of an ETL job, so it is not processed agai.  

**Scenario cue**: "serverless ETL / discover schema / catalog data / transform before analysis" → Glue.

## Amazon AppFlow
**Managed data integration** to securely transfer data between **SaaS apps and AWS** without writing code.
- Connects SaaS (Salesforce, ServiceNow, Slack, Zendesk, Google Analytics, SAP, etc.) to AWS (**S3, Redshift**) and back.
- **Bidirectional** transfer, on a **schedule**, on an **event**, or **on demand**.
- Built-in **transformations** (filter, map, mask, validate) during transfer.
- Encrypted in transit; can run over **PrivateLink** for private data flows.

**Scenario cue**: "move data between a SaaS app (like Salesforce) and AWS, no custom code" → AppFlow.

**How they chain (common exam pipeline)**

- **AppFlow** pulls SaaS data into **S3** → **Glue** crawls/cataloges and transforms it → **Athena** queries it with SQL → **QuickSight** visualizes it in dashboards.

**Confusion pairs (traps)**

- **Glue vs AppFlow**: Glue = ETL between AWS/data-store sources + schema catalog. AppFlow = specifically **SaaS-to-AWS** transfer, no code.
- **Athena vs Redshift**: Athena = serverless, ad-hoc SQL on S3, pay-per-query. Redshift = provisioned data warehouse for large-scale, frequent, complex analytics.
- **Athena vs QuickSight**: Athena = the query engine (SQL). QuickSight = the visualization layer (dashboards). QuickSight often queries _through_ Athena.
- **Glue Data Catalog** is the shared metastore, remember it is used _by_ Athena, not part of Athena.
